# Number Frequency Counter
A simple Java program that searches for a number in an array and counts how many times it appears.

## Features
- Searches for a user-entered number
- Counts the number of occurrences
- Displays the frequency of the number
- Displays a message if the number is not found

## Technologies Used
- Java
- Scanner class
- Arrays
- For loop
- If-else statements
- Boolean variables

## How to Run
1. Download NumberFrequency.java.
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac NumberFrequency.java
   
4. Run the program:
   java NumberFrequency
## Example Output
Enter a number to search: 10
Number appears 3 times.

## Purpose
This project was created to practise Java fundamentals, array traversal, counting occurrences, and checking whether an element exists in an array.
